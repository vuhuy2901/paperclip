# Operations

The API is stateless apart from the database and artifact volume. `worker` claims queued runs and records ordered events. Cancellation uses guarded transitions, a run-status monitor, and runner/gateway process termination; the run keeps its collected evidence and releases its lease. Back up the PostgreSQL metadata, `data/artifacts`, and managed repository/worktree volume together.

Compose runs Core/Worker and Paperclip against the Ollama container by default. Ollama pulls `OLLAMA_MODEL` into the persistent volume before dependent services become healthy; no host gateway, Codex CLI login, OpenRouter key, or `host.docker.internal` route is required. Paperclip runs `local_trusted` on localhost and its adapter probes Ollama directly before agents become ready. The review UI uses the Core service token in this development deployment. A production deployment still needs a real secret manager, board/PO session, task-container hardening, resource limits, backup restore drills, and a configured model budget.
